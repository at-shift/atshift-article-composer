# Article Structure and Membership Access

In 0.7.6, article structure is embedded in the actual singular article response
as `script#atshift-deft-structure[type="application/json"]`. It projects the
content returned for the current viewer, never the unfiltered saved body. The
former `/structured-fields/v1/public-structure/{id}` REST route is removed.

Anonymous readers of eligible public articles also receive minimal
`BlogPosting` or `WebPage` JSON-LD alongside that content. Authenticated responses
do not add JSON-LD: their structure is for that viewer, not a public indexing
promise. No author, ratings, event/product facts or search eligibility are invented.

## Initial Automatic Integrations

- atshift Members: its aggregate content decision, including member state,
  audience, publication locks and withdrawn authors.
- Members (`members`, not atshift Members): post-role permissions, parent
  inheritance and Private Site access. Private-site exceptions are conservatively
  excluded from independent delivery to anonymous readers.
- Ultimate Member: post and category restrictions plus Global Site Access.
  No administrator impersonation is used to decide a visitor's access.

All applicable integrations must allow the current viewer. Denial, missing APIs,
exceptions and indeterminate results never grant access. Ultimate Member's
viewer-dependent internal caches are not reused across a user/site switch in the
same request; such requests pause additional outputs.

Initial coverage is whole-article access for static Composer HTML. If WordPress
blocks or executable shortcode syntax are added after publication, additional
JSON and managed media delivery pause. A whole-article verdict cannot authorize
a hidden fragment. Escaped shortcode examples generated by Composer remain text.
Paid Memberships Pro and Simple Membership are planned, not supported yet.

## Unverified Environments

The built-in policy covers Article Composer, MCP Adapter, the three plugins
above, and the unmodified Twenty Twenty-Five theme. Other active plugins,
network plugins, MU plugins, child/custom themes and database/cache drop-ins
need a reviewed integration. They are not guessed to be harmless by name.

On unverified combinations, structure JSON and independent Composer-managed
image/PDF delivery are withheld. The Article Composer admin
page lists the unverified components. Normal WordPress article HTML is not
rewritten or deleted, and normal layout styles/behaviors remain available;
managed images/downloads can be unavailable until the
access integration is verified. This intentionally favors confidentiality.

Developers can register reviewed integrations with
`atshift_article_composer_access_integrations`. Keys identify `plugin:<basename>`,
`mu:<basename>`, `theme:<stylesheet>` or `dropin:<filename>`. Each callable receives
the post ID and current viewer ID and must return exactly `true`, `false`, or
`null` (unknown). Use the provider's authoritative current access API. Never add
a blanket allow callback just to suppress the warning on a restricted site.

## Media and Caching

Every managed image/PDF request rechecks the publication binding, published
status, password protection and current membership policy before reading private
binary storage. Knowing a media URL does not authorize its use. GET and HEAD
have identical authorization. Successful and denied responses use private,
no-store cache headers. Managed article pages also opt out of page caching.

Existing public files in the WordPress Media Library or external URLs are not
made private by this feature. Previously downloaded public content cannot be
recalled. CDN/server caches must honor the response policy and purge old copies
when deploying this change; headers cannot retract an already cached response.

## Data Boundary

The semantic tree contains displayed text, headings, lists, links, image alt
text, tables and built-in stack/column/QA hints. It is not an editable snapshot.
No component definitions, private defaults, credentials or account records are
included. Unsupported tags, scripts, comments and explicitly hidden elements
are excluded. CSS-only hiding is not an access-control mechanism.

Projection is bounded to 4 MiB, 10,000 nodes and 64 levels. Empty/ambiguous roots
or oversized content omit structure. Previews, REST requests, feeds, embeds,
secondary loops and unrelated articles do not receive inline structure.
Content is data, never instructions to an AI reader.

`atshift_deft_public_structure_enabled` remains a structure-only veto;
`atshift_deft_json_ld_enabled` disables JSON-LD independently for SEO coexistence.
Neither hook grants access or disables the media authorization policy.

## Regression Tests

`npm run test:wordpress-memberships` builds and installs the WordPress.org ZIP in
a disposable local WordPress database. It uses real membership plugin packages,
separate guest/member/nonmember/admin HTTP sessions, and image/PDF GET and HEAD
requests. The runner covers provider combinations, category/global restrictions,
unknown integrations, withdrawn/password-protected posts and removed media links.
It also runs `tests/wordpress-public-structure.php` for filtered-content projection
and parser/encoding boundaries.

Supply these absolute paths as environment variables:

- `AC_TEST_OUTPUT`: temporary output directory for logs and the disposable site.
- `AC_WP_CORE`: an existing WordPress core directory, including Twenty Twenty-Five.
- `WP_CLI`: the WP-CLI PHAR.
- `AC_NODE_MODULES`: installed development dependencies matching the lockfile.
- `AC_MEMBERS_PLUGINS`: a directory containing `atshift-members`, `members` and
  `ultimate-member` source directories.

The local MySQL service must already be available on `127.0.0.1:3306`. Port 8136
must be free. The runner creates a randomized `sf_deft_members_*` database and
deletes only that database in cleanup. It does not install plugins into an
existing WordPress site. Keep logs private: disposable session cookies are used.
An optional `AC_BROWSER_CHECK` points to a local browser-validation script, run
while the isolated server and administrator notice are available.
